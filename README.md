# Chouksep Data Desk (`chouksep.github.io`)

Static data-backed journalism site ready for GitHub Pages.

## Quick Deploy
1. Create a public repository named `chouksep.github.io` on GitHub (or any project repo).
2. Upload `index.html` and `.nojekyll` to the `main` branch root.
3. In **Settings → Pages**, set **Source** to **Deploy from a branch** (`main` / `/ (root)`).
4. Your site will be live at `https://chouksep.github.io/`.

## Pen-Name Note
`https://github.com/chouksep` currently displays a full name on the profile. If you intend to publish anonymously under a pen name, create a separate GitHub account for that pen name and set a noreply commit email before pushing.
